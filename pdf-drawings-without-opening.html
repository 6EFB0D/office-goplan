LeafDesk · 用途ガイド

図面PDFを開かずに見分けるには

ファイルサーバに並んだ図面・注文書・検査資料。目的の1枚を探すたびに PDF を開いて閉じる作業は、思った以上に時間を食います。ここでは「開かずに見分ける」考え方と、Windows アプリ LeafDesk（旧称 pdfHandler）での整理の仕方をまとめます。

よくある困りごと

  • ファイル名だけでは図番・改訂・添付種別が分からない
  • エクスプローラーで1つずつ開くと、Acrobat / Edge の起動待ちが続く
  • ネットワークドライブだと、開くたびに待ち時間が積み重なる
  • 見つけたあと、そのままリネームや結合まで行きたい

Windows だけでもできること・限界

エクスプローラーの「大きいアイコン」やプレビューウィンドウは、手軽な第一歩です。ただし次の点で足りないことがあります。

  • フォルダを横断して「見ながら名前を変える」流れが弱い
  • 複数ページ PDF の中身を、一覧のままめくって選ぶ操作がしづらい
  • 見分けたあとの結合・分割・ページ並べ替えは別ツールになりがち

ビューア単体（表示だけ得意なソフト）も有用ですが、「フォルダで見分ける → その場で整理する」まで一気通貫、という用途には別の道具が向きます。

開かずに見分ける、基本の流れ

  1. フォルダを開く — 図面や注文書が置いてある共有フォルダを左ペインで選ぶ
  2. サムネイルで見比べる — 中央の一覧で枠・図番・レイアウトの違いを把握する
  3. 必要ならプレビュー — 右側でページをめくり、ページストリップで複数枚を確認する
  4. そのまま整理 — F2 でリネーム、結合・分割、ページの抜き出しや並べ替えへ進む

LeafDesk が向いている場面

  • 図面・注文書・見積依頼など、見た目で種別が分かる PDF が多い
  • ファイルサーバ／ネットワークドライブ上で探すことが多い
  • 見つけたあと、名前付け・結合・ページ整理まで同じ画面で済ませたい
  • 買い切りの Windows アプリで、試用してから導入したい

逆に、ブラウザだけで完結したい場合や、注釈の作成・高度な CAD 連携が主目的の場合は、別製品の方が合うことがあります。
