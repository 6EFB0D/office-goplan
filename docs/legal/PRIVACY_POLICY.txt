Office Go Plan プライバシーポリシー

最終更新日: 2026年7月12日

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

第1条（定義および趣旨）

1. Office Go Plan（以下「当サービス」）は、ユーザーのプライバシーを尊重し、個人情報の保護に努めます。
2. 本ポリシーは、当サービスが運営するウェブサイト（office-goplan.com 上のサイトを含みます）および当サイトが案内・提供するソフトウェア（pdfHandler、ZipSearch、PictCompその他。以下「本製品等」）における、個人情報およびこれに準ずる情報の取扱いを説明します。
3. 「処理対象データ」とは、ユーザーが本製品等のソフトウェアに読み込ませ、表示・検索・変換・圧縮・結合その他の処理の対象としたファイルおよびその内容（アーカイブ内のファイル名・メタ情報等を含みます）をいいます。
4. 屋号「Office Go Plan」とドメイン名（office-goplan.com）の表記は一致しませんが、同一の事業者が運営します。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

第2条（処理対象データについて）

1. 処理対象データは、ユーザーのローカル環境でのみ処理されます。
2. 処理対象データの本体およびその内容は、当サービスのサーバに送信しません。当サービスに共有されず、第三者にも提供しません（次条の購入・認証等に必要な情報を除きます）。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

第3条（収集する情報）

当サービスでは、業務・サービスの実態に応じ、次の情報を取り扱うことがあります。

1. お問い合わせ: 氏名、メールアドレス、その他連絡に必要な情報
2. 購入、見積、請求、銀行振込に係る取引: 会社名、部署名、担当者名、請求先住所、電話番号、メールアドレス、振込名義、取引履歴等
3. ライセンスの付与・オンライン検証等: ライセンスキー、メールアドレス、ハードウェア識別子、デバイス表示名、アプリバージョン、アクティベーション状態等（製品により異なります）
4. 決済: カード番号等は Stripe が処理し、当サービスは保持しません
5. アンケート・ご意見（Google フォーム等）: ご記入内容（フォームごとに異なります）
6. 技術情報・アクセス解析: IP アドレス、ブラウザの種類、アクセス日時、Google アナリティクス（GA4）による統計的情報（Cookie 等を用います）
7. アップデート確認: GitHub API 等へのリクエスト（個人を特定する情報は送信しません）

ご記入・ご送信にあたってのお願い: お問い合わせやフォームに、クレジットカード番号・口座番号・パスワード・機微な個人情報を記載しないでください。決済は Stripe が定める画面等でのみ行ってください。

第4条（利用目的）

1. お問い合わせへの対応
2. 本製品等の提供、ライセンスの販売・発行・認証・デバイス数の管理、不正利用の防止
3. 購入・請求・決済・入金確認およびこれらに関する連絡
4. サービスの提供、維持、改善、サポート
5. 当サイトの利用状況の把握・分析（GA4）
6. アンケート結果・フィードバックの分析および改善
7. 重要な通知
8. 法令に基づく対応

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

第5条（第三者提供・業務委託）

1. 当サービスは、法令に基づく場合を除き、ユーザーの同意なく個人情報を第三者に提供しません。
2. 目的達成のため、次の事業者のサービスを利用し、必要な範囲で情報が処理される場合があります。各社のプライバシーポリシーもご確認ください。
   (1) Stripe, Inc.（決済）
   (2) Supabase Inc. 等（ライセンス・デバイス情報の保管、Edge Functions 等）
   (3) Resend 等のメール送信サービス（購入・ライセンス関連メール）
   (4) GitHub, Inc.（アップデート情報の取得、配布案内）
   (5) Google LLC（GA4、Google フォーム等）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

第6条（インターネット通信）

本製品等のソフトウェアは、主に次の場合にインターネット通信を行います。

1. ライセンスの購入依頼、認証、デバイスの登録・解除
2. アップデート確認（GitHub API 等）
3. ヘルプ・サポートリンクをクリックした場合
4. 当サイト閲覧時のアクセス解析（ブラウザ）

処理対象データの本体を、上記以外の目的でサーバへ送信することはありません。

第7条（データの保存）

1. アプリケーション設定およびライセンス関連のローカル情報は、ユーザーのコンピューター内に保存される場合があります。
2. サーバ側のライセンス・デバイス情報は、利用目的の達成に必要な期間保持し、不要後は削除または匿名化します。
3. Cookie: 利便性向上や GA4 のため Cookie を使用する場合があります。ブラウザ設定で制限できる場合があります。

第8条（子どもの個人情報）

本製品等は、13歳未満の子どもを主たる対象としていません。13歳未満の方が使用する場合は、保護者の同意を得てください。

第9条（セキュリティ）

当サービスは、取り扱う情報の漏えい、滅失、毀損の防止のため、合理的な安全管理措置を講じます。ローカルファイルのセキュリティは、ユーザー環境に依存します。

第10条（ユーザーの権利）

1. ソフトウェアの使用停止・アンインストール
2. ローカル設定ファイルの削除
3. 保有個人データに関する開示等の請求（法令の範囲内）
4. 本ポリシーについての質問

請求は第12条までご連絡ください。本人確認のうえ、法令に従い対応します。
