# 書類管理アプリ（公開リポジトリから除外）

ここにあった **見積・注文・請求・領収** 向けのローカル GUI アプリのソースや設定は、機密情報・社内運用を含むため **このリポジトリには含めていません**（過去コミットの履歴からも削除済みです）。

## 退避について

- 完全なコピーは、**Git の外**に退避してあります（フォルダ名の例: `office-goplan-private-retreat\invoice-app`）。場所の詳細と注意事項は、退避先の `00_RETREAT_MANIFEST.md` を参照してください。
- 開発の主阵地は、必要に応じて **`backoffice`** 側の書類管理アプリと揃えてください。

## このディレクトリで「公開する」もの

- 本ファイル（`README.md`）と、同梱の `.gitignore`（誤コミット防止）のみです。
- `.py` や `config.py`、`transactions.xlsx` 等をここに戻しても、`.gitignore` により **コミット対象になりません**。気づいたら退避フォルダや社内リポジトリ側で管理してください。

## 履歴を書き換えたあとの push

リモートへ反映するには **`git push --force-with-lease`** が必要になることがあります。共有者がいる場合は事前に共有してください。
