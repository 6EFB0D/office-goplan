## 2. 「ご連絡の種類」に購入系を追加（必須）

質問「２．ご連絡の種類を選択ください」の選択肢に、次を**追加**してください（既存4つは残す）。

| 追加する選択肢（文言そのまま） |
|---|
| `ご購入の相談（個人）` |
| `法人・まとめ購入の相談` |

追加後の並び案:

1. 改善要望  
2. 不具合情報  
3. アイディア  
4. **ご購入の相談（個人）**  
5. **法人・まとめ購入の相談**  
6. その他  

---

## 3. 事前入力リンクの取り方（追加後）

1. 編集画面 → 右上「︙」→ **事前入力した URL を取得**
2. 製品 = `LeafDesk (旧 pdf-handler)`
3. 種類 = `法人・まとめ購入の相談`
4. 本文に下のテンプレを貼る
5. 「リンクを取得」→ その URL を `leafdesk.html` の「法人・まとめ購入の相談」ボタンに設定

（サイト側は仮で「その他」＋本文テンプレの事前入力 URL を入れ済み。選択肢追加後に種類を差し替えてください。）

### 本文テンプレ（法人）

```
【法人・まとめ購入のご相談】
・会社名：
・ご担当者名：
・想定台数（例: 5 / 10 / 20）：
・ご利用部署・用途（図面／注文書 など）：
・希望の連絡手段（メール／電話）：
・その他ご要望：
```
