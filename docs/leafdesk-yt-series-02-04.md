## 共通ルール

- ダミーデータのみ。実顧客名・実図面は使わない。
- ツリーは Work 配下またはデモ用フォルダ。個人フォルダを映さない。
- 有償機能（回転・結合・分割）は試用中画面で撮影。必要なら字幕で「Standard／試用で利用可」と一言。
- 本編が 110 秒超になりそうなら分割を再検討。
- 既存 `leafdesk-po`（注文書の切り出し）とは棲み分け: YT-04 は分割ダイアログの3方式。

### UI 正式名称（台本用）

| 操作 | 場所 |
|------|------|
| サムネイルサイズ | 表示 → サムネイルサイズ → 小／中／大／特大 |
| ストリップ拡縮 | ストリップ右の ＋／−、または Ctrl+ホイール |
| プレビュー拡大・縮小 | プレビューツールバー 🔍+／🔍−（ホイール可） |
| プレビューパン | 拡大後、プレビュー上をドラッグ |
| 表示中1ページ回転 | 表示 → 表示中の1ページだけを回転、またはストリップ右クリック |
| 全ページ回転 | リボン ↺／↻／⇅、または 表示 → 選択中PDFの全ページを回転 |
| 結合 | PDFファイルの結合（順序・保存先・高度な設定しおり） |
| 分割 | ページ範囲で分割／1ページずつ分割／等分割 |

## YT-02｜見てから整える

### メタデータ案

- **タイトル**: `LeafDesk｜PDFの回転と、拡大縮小表示（サムネ・ストリップ・プレビュー）`
- **説明文（要約）**: LeafDesk。今回は、PDFファイルやページの回転、拡大縮小表示について紹介します。サムネイルサイズ、ページストリップの拡縮、プレビューの拡大・パンのあと、表示中ページ／ファイル全体の回転まで。
- **タグ**: LeafDesk, PDF, サムネイル, ページストリップ, プレビュー, 回転, 図面PDF, Windows

### ナレーション全文（TTS用／字幕用）

形式: `(key, voice, speak, subtitle, shot)`

```
("1",  Nanami, "リーフデスク。", "LeafDesk。", "card")
("2",  Nanami, "今回は、ピーディーエフファイルやページの回転、拡大縮小表示について紹介します。", "今回は、PDFファイルやページの回転、拡大縮小表示について紹介します。", "card")
("3",  Keita,  "フォルダにファイルが多いと、小さいサムネイルでは見分けづらいことがあります。", …, "desk-small")  # A案
("4",  Keita,  "表示メニューの、サムネイルサイズから、ちゅうを選びます。", "表示メニューのサムネイルサイズから、中を選びます。", "thumb-menu")  # 小→中、以降は中を維持（通し撮り）
("5",  Keita,  "ページストリップは、プラスとマイナスで拡大・縮小できます。", …, "strip-zoom")
("6",  Keita,  "…プレビューをドラッグすると、表示をずらして見たい場所を表示できます。", "拡大は虫めがねの＋、またはCtrl＋ホイール。ドラッグで表示位置を動かせます。", "preview-zoom-pan")
("7",  Keita,  "ファイル内のページを回転するときは、ストリップ上部のアイコンで操作できます。", …, "rotate-one")  # 2ページ目を回転
("8",  Keita,  "選択したファイル全体なら、サムネイル上部のアイコンで回転します。", …, "rotate-all")
```

結合・分割へのつなぎは削除。中サイズ維持。カーソルは操作対象アイコン中心へ。  
補足: デモPDFのページサイズは A4。以前の映像で縦横比が崩れて見えたのはキャプチャ時の引き伸ばしが原因。選択ハイライトが灰色だったのはウィンドウ非アクティブ時。

### 撮影チェックリスト（YT-02）

**デモフォルダ**: `%USERPROFILE%\Documents\LeafDesk-HP-Demo\Work\回転確認\`（仮）

| # | 素材 | 内容 | メモ |
|---|------|------|------|
| A | 多ページ図面PDF（縦横混在） | 3〜5ページ。1ページ目は正しい向き、2ページ目は90°ずらし | 回転デモ用 |
| B | スキャンっぽい横図面1本 | 全ページが横向き | 全ページ回転用 |
| C | 初期UI | サムネイルサイズ＝小、ストリップ zoom＝1、プレビュー 100% | 開始状態を揃える |

**ショット順**

1. `desk-small` … 小サムネで縦横混在が見えにくい状態
2. `thumb-size` … 表示 → サムネイルサイズ → 大（または特大）
3. `strip-zoom` … ストリップ ＋ を2段ほど／− で戻すでも可（変化が分かる方）
4. `preview-zoom-pan` … 🔍+ → 図番付近へドラッグパン → 必要なら戻す
5. `rotate-one` … 向きの違うページを選び、右90°（表示中1ページ）
6. `rotate-all` … 横向きファイルを選び、リボンで全ページを正しい向きへ
7. `desk-final` … 整った一覧のワイドショット

**注意**

- PageStripZoomLevel は撮影後に UI 設定を戻せること（既存バックアップ手順流用）。
- ツリーに個人フォルダが出ないこと。
- 回転後は保存結果がサムネ／ストリップに反映されるまで待ってから次カット。

### YouTube／LinkedIn 用一言

- YT: シリーズ「結合・分割・回転」の導入編。表示を整えてから加工へ。
- LinkedIn: 図面PDFの向き直しまで、別ビューアを開かずに LeafDesk 上で完結。

### 撮影チェックリスト（YT-03）

| 素材 | 内容 |
|------|------|
| 表紙.pdf | 1ページ。しおり「表紙」付きだと説明しやすい |
| 図面-A.pdf / 図面-B.pdf | 各1〜2ページ。可能なら既存しおり |

1. ▲上へ／▼下へでの順序変更
