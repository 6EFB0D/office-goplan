## 共通ルール

- ダミーデータのみ。実顧客名・実図面は使わない。
- ツリーは Work 配下またはデモ用フォルダ。個人フォルダを映さない。
- 有償機能（回転・結合・分割）は試用中画面で撮影。必要なら字幕で「Standard／試用で利用可」と一言。
- 本編が 110 秒超になりそうなら分割を再検討。
- 既存 `leafdesk-po`（注文書の切り出し）とは棲み分け: YT-04 は分割ダイアログの3方式。

### UI 正式名称（台本用）

| 操作 | 場所 |
|------|------|
| サムネイルサイズ | 表示 → サムネイルサイズ → 小／中／大／特大 |
| ストリップ拡縮 | ストリップ右の ＋／−、または Ctrl+ホイール |
| プレビュー拡大・縮小 | プレビューツールバー 🔍+／🔍−（ホイール可） |
| プレビューパン | 拡大後、プレビュー上をドラッグ |
| 表示中1ページ回転 | 表示 → 表示中の1ページだけを回転、またはストリップ右クリック |
| 全ページ回転 | リボン ↺／↻／⇅、または 表示 → 選択中PDFの全ページを回転 |
| 結合 | PDFファイルの結合（順序・保存先・高度な設定しおり） |
| 分割 | ページ範囲で分割／1ページずつ分割／等分割 |

**ショット順**

- 回転後は保存結果がサムネ／ストリップに反映されるまで待ってから次カット。

| # | 素材 | 内容 | メモ |

| D | 選択順 | わざと B→C→A で選び、ダイアログで A→B→C に直す | 順序変更が伝わる |

**ショット順**

1. `card` … 黒背景＋ロゴ（Nanami）
2. `desk-list` … 3ファイルが別々に並ぶ一覧（サムネ中推奨）
3. `select-merge` … 複数選択 → リボン／メニューから結合
4. `order` … リストで表紙を選び **上へ** で先頭へ
5. `outline` … 高度な設定を開き、しおり関連チェックを ON（または既に ON を示す）
6. `save-name` … **先頭ファイル名を使う**（上書き）か、外して新名（例: `提出セット_デモ社様.pdf`）かを示す
7. `save-run` … **結合実行**
8. `result` … できたファイルを開き、ページ順（表紙→図面）をストリップ／プレビューで確認。しおりが取れるなら確認
9. `desk-final` … 結合結果がフォルダに1本あるワイドショット

**注意**

- 有償機能。試用中画面で撮影可。必要なら字幕で「Standard／試用で利用可」。
- ツリーに個人フォルダを出さない。
- 結合中ダイアログ／完了まで待ってから `result`。
- 旧スクショ `merge-dialog.png` は簡略版の可能性あり。撮影時は現行 UI のラベル優先。

### YouTube／LinkedIn 用一言

- YT: 提出用に表紙と図面を1つへ。順番・しおり・名前まで結合ダイアログで完結。
- LinkedIn: ファイルサーバ上のPDFを、別ツールなしで提出セットに束ねる。

### デモPDF

`注文書_会社順.pdf`（9ページ、各ページは色分け。A=青、B=緑、C=橙。部品番号を大きく表示）

| ページ | 中身 |
|--------|------|
| 1–3 | A社様 P1, P2, P3 |
| 4–6 | B社様 P1, P2, P3 |
| 7–9 | C社様 P1, P2, P3 |
