LeafDesk

pdf Handler for Windows（旧称 pdfHandler）

ファイルサーバ上の図面・注文書 PDF を、開かずにサムネイルで見分け、そのまま並べ替え・結合・整理できる Windows デスクトップアプリです。

概要

フォルダツリー、PDF 一覧、プレビューを 3 ペインで表示。図面枠・図番・レイアウトの違いをサムネイルとページストリップで確認しながら、目的のファイルをすばやく特定できます。見つかったあとは、プレビュー表示のまま F2 でリネーム、結合・分割、複数ページの選択・複製・並べ替え、ヘッダ・フッターまで、同じ画面から続けて操作できます。

サムネイル判別 / F2リネーム / ページストリップ / 複数ページ選択 / 図面・注文書 / 結合 / 分割 / ページ編集 / ヘッダ・フッター / お気に入りフォルダ

こんな場面で

見た目の差がはっきりしている文書ほど、開かずに探す効果が大きいです。

  • 図面管理

    図面枠・図番・形状を見て、目的の図面を瞬時に判別できます。

  • 顧客注文書の管理

    顧客ごとにレイアウトが異なるため、見た目で識別しやすいです。

  • 注文書の添付図面管理

    図面・仕様書・検査基準書などを、いちいち開かずに区別できます。

  • 見積依頼書・要求仕様書の管理

    顧客図面や仕様書が添付される案件でも、目的の資料を探しやすくなります。

  • 契約書管理

    表紙で識別できる場合に有効です。

  • テキスト中心の帳票

    サムネイルが似て見えやすく、効果は限定的です。

画面で見る

掲載画像は説明用のダミー PDF です。実在の顧客・図面ではありません。

図面管理

形の違う図面をサムネイルで並べ、右側プレビューとページストリップで内容を確認

プレビューしながらリネーム

サムネイル選択中に F2。右側のプレビューを見ながら、その場でファイル名を変更できます

顧客注文書

レイアウトの異なる注文書を一覧し、開かずに見分けながら整理

添付の見分け

図面・検査基準書などが混在しても、サムネイルの見た目で種別を判別

見積依頼・要求仕様

見積依頼書と添付図面を同じフォルダで扱い、目的資料へすばやく到達

複数ページの操作

ページストリップで Ctrl／Shift により複数ページを選び、複製・並べ替え・別ファイルへのコピー／切り出しまで一気に

機能・特徴

  • 視覚検索: 3 ペイン構成とサムネイル／ページストリップで、開かずに目的 PDF を特定
  • PDFプレビュー: ページ送り、拡大・縮小。プレビュー上から表示中ページの回転・削除も可能
  • ファイル操作: F2 キーでプレビュー表示のままリネーム。コピー、ペースト、削除にも対応
  • PDF結合: 複数 PDF の順序を調整して 1 つの PDF に結合（しおりの引き継ぎにも対応）
  • PDF分割: ページ範囲、1ページずつ、等分割の 3 パターンに対応
  • ページ回転: プレビュー／サムネイルの表示中ページ、または選択 PDF の全ページを回転（有償機能）
  • ページ編集: 複数ページの選択・複製・削除・並べ替え、別ファイルへのコピー／切り出し、挿入に対応
  • 文書整備: ヘッダ・フッター、ページ番号、PDF バインダー管理を搭載
  • ライセンス管理: アプリ内購入、ライセンスキー入力、デバイス管理に対応

ダウンロード

最新版は GitHub Releases で公開

GitHub Releases の ページ下部「Assets」 から Windows 版インストーラ（setup.exe）をダウンロードしてください。上部の「Source code (zip)」はインストーラではありません。版番号や変更内容は Releases の各ページをご覧ください。

うまくいかないとき（セキュリティでブロックされる場合）

ブラウザや Windows のセキュリティ警告（SmartScreen 等）で .exe のダウンロードや実行ができない 場合は、Assets の LeafDesk-*-prod-setup.zip（旧版は PdfHandler-*-prod-setup.zip）をダウンロードし、解凍後の setup.exe を実行してください。
