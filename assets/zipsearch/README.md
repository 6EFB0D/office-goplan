# ArkLidFind スクリーンショット（パス名 zipsearch 据え置き）

このフォルダには ArkLidFind の UI キャプチャを配置します。

## 現在配置中

| ファイル名 | ページ上の位置 | 説明 |
|------------|----------------|------|
| `gui-main.png` | 1 枚目 | 検索設定画面 |
| `gui-results.png` | 2 枚目 | log4net 解析 ON + ERROR 絞り込み + 結果一覧 |
| `gui-rolling.png` | 3 枚目 | RollingFile 兄弟の横断 |
| `web-main.png` | （製品ページでは未使用） | 旧画面。製品ページの主案内には出さない |
| `arklidfind_blue.png` | ヒーロー | 製品ロゴ（現行） |
| `zipsearch_blue.png` | （旧） | 参照しない |

## 画像の差し替え

スクリーンショットを更新する場合は、同名で上書き保存し、`zipsearch.html` のキャプションと合わせて確認してください。
