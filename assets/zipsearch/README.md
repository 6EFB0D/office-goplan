# ZipSearch スクリーンショット

このフォルダには ZipSearch の UI キャプチャを配置します。

## 現在配置中

| ファイル名 | ページ上の位置 | 説明 |
|------------|----------------|------|
| `gui-main.png` | 1 枚目 | 検索設定画面（正式リリース時に ZIP / HTTP URL 版へ差し替え予定） |
| `gui-results.png` | 2 枚目 | log4net 解析 ON + ERROR 絞り込み + 結果一覧（v0.5.0） |
| `gui-rolling.png` | 3 枚目 | RollingFile 兄弟通知 ON + ローテーション横断（v0.5.0） |
| `web-main.png` | （未使用） | 旧 Web 版キャプチャ。必要時に再利用 |
| `zipsearch_blue.png` | ヒーロー | 製品ロゴ |

## 正式リリース時の差し替え（1 枚目）

検索設定画面で以下が見えるキャプチャに差し替え:

- ローカル ZIP パス
- HTTP(S) URL
- 検索キーワード入力済み（検索前）

差し替え後は `zipsearch.html` の 1 枚目キャプションと `screenshot-note` を更新してください。

## 画像の差し替え

スクリーンショットを更新する場合は、同名で上書き保存し、`zipsearch.html` のキャプションと合わせて確認してください。
